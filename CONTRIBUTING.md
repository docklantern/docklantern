# Contributing

DockLantern is currently in the design phase. Requirements, testing scenarios, and architecture/security review are welcome.

1. Read the PRD and existing architecture decision records.
2. Open an issue before significant architectural or scope changes.
3. Use a focused branch and pull request; document validation and security implications.
4. Add or supersede an ADR for durable design changes.

Do not submit private Compose files, API tokens or credentials. The coding style and build/test workflow are pending language selection.

**Licensing:** A license has not been selected. This repository does not yet grant an open-source reuse license.
