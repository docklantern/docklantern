# ADR 0006 — Runtime Selection

**Status:** Proposed  
**Date:** 2026-10-21

## Candidates
Go with standard HTTP/template support and simple frontend; Python/FastAPI with server-rendered HTML and lightweight scheduling.

## Evaluation criteria
Idle memory, startup, binary/image size, Docker/Compose libraries, maintainability, testability, security, AMD64/ARM64 packaging and developer productivity.

## Decision
No stack chosen yet. Do not add application source scaffolding until accepted.
